Отформатируйте ответ строго как корректный JSON-объект. Выведите только сам JSON, без пояснений, комментариев и блоков кода Markdown.

Формат ответа:

{
  "source": "СЛОВО_КОТОРОЕ_ЗАМЕНЯЕМ",
  "distractor1": "ВЫБРАННОЕ_СЛОВО_1",
  "distractor2": "ВЫБРАННОЕ_СЛОВО_2",
  "distractor3": "ВЫБРАННОЕ_СЛОВО_3"
}

Если нужное число дистракторов не равно 3, сохраните тот же формат и добавьте или удалите поля distractor по порядку:
- если нужен 1 дистрактор — выводите только distractor1;
- если нужны 2 дистрактора — distractor1 и distractor2;
- если нужны 4 дистрактора — distractor1, distractor2, distractor3 и distractor4;
- и так далее.

Требования к JSON:
- поле source должно присутствовать;
- значение source — исходное целевое слово;
- включите ровно столько полей distractor*, сколько требуется, без лишних полей;
- имена distractor должны быть пронумерованы подряд, начиная с distractor1, без пропусков номеров;
- значение каждого distractor — строка;
- не добавляйте запятую после последнего поля объекта (запрещена «висящая запятая» в конце);
- не помещайте ответ в блок Markdown;
- после JSON не добавляйте никакого поясняющего текста.
