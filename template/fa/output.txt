خروجی را به صورت یک شیء JSON کاملا معتبر قالب بندی کن. فقط خود JSON را خروجی بده و هیچ توضیح، کامنت، یا بلوک کد Markdown اضافه نکن.

قالب خروجی به صورت زیر است:

{
  "source": "WORD_TO_BE_REPLACED",
  "distractor1": "WORD_YOU_CHOOSE_1",
  "distractor2": "WORD_YOU_CHOOSE_2",
  "distractor3": "WORD_YOU_CHOOSE_3"
}

اگر تعداد واژه های مزاحمِ لازم 3 نباشد، همین قالب را نگه دار و فیلدهای distractor را به ترتیب اضافه یا حذف کن:
- اگر 1 واژه مزاحم لازم است، فقط distractor1 را خروجی بده؛
- اگر 2 واژه مزاحم لازم است، distractor1 و distractor2 را خروجی بده؛
- اگر 4 واژه مزاحم لازم است، distractor1، distractor2، distractor3، و distractor4 را خروجی بده؛
- و به همین ترتیب.

الزامات:
- فیلد source باید وجود داشته باشد؛
- مقدار فیلد source باید همان واژه هدف اصلی باشد؛
- دقیقا به تعداد لازم فیلد distractor داشته باش و فیلد distractor اضافه تولید نکن؛
- فیلدهای distractor باید از distractor1 شروع شوند و بدون پرش شماره گذاری شوند؛
- مقدار هر فیلد distractor باید رشته باشد؛
- در انتهای شیء JSON ویرگول اضافه نگذار؛
- بلوک کد Markdown تولید نکن؛
- هیچ متن توضیحی تولید نکن.
